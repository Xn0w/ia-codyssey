# AI 기반 소셜 미디어 콘텐츠 자동 생성 시스템 — 워크플로우 설명 문서

## 1. 프로젝트 개요

하나의 주제(키워드)를 입력하면 Make 자동화 워크플로우를 통해 **인스타그램 / 블로그 / X(구 트위터)** 3개 플랫폼에 맞는 텍스트와 대표 이미지를 동시에 생성하고, 결과물을 노션 데이터베이스에 플랫폼별로 자동 저장하는 시스템이다. 생성형 AI(Google Gemini)로 텍스트를, 이미지 생성 AI(PiAPI/NanoBanana)로 대표 이미지를 만들며, 각 플랫폼의 특성(글자 수, 해시태그, 톤앤매너)을 프롬프트 설계에 반영했다.

**과제 선택 사유**: B2의 1~3번 과제 중 3번을 선택했다. Router로 분기를 나누면 각 분기(A/B/C)마다 독립적인 API 연결과 플랫폼별 프롬프트 구성을 서로 다르게 적용·비교할 수 있어, 플랫폼별 콘텐츠 자동화의 차이를 명확히 설계하고 검증하기에 적합하다고 판단했다.

### 단계별 상세 설명

1. **Google Forms (트리거)** — 사용자가 주제를 입력하면 워크플로우가 즉시 실행된다.
2. **Router (분기)** — 하나의 입력을 3개 경로로 동시에 분기하여 플랫폼별 처리를 병렬로 수행한다.
3. **Google Gemini AI (텍스트 생성)** — 분기마다 별도 프롬프트를 사용해 플랫폼 특성에 맞는 톤앤매너와 글자 수로 텍스트를 생성한다. `A/B/C_ai_prompt.png`에는 실제 입력된 프롬프트 원문이 캡처되어 있으며, 톤앤매너 지시가 프롬프트 내에 명시적으로 포함되어 있다.
   - **인스타그램(A)**: 짧은 캡션 + 해시태그 10개 내외. 프롬프트에 "**친근하고 감성적인 톤으로 작성**", "2~3문장의 짧은 본문(이모지 1~2개 포함 가능)", "해시태그는 주제와 관련된 키워드로 구성"이라고 명시되어 있음
   - **블로그(B)**: 500자 이상 본문 + 소제목 구조. 프롬프트에 "**정보 전달형 톤앤매너**", "가독성을 위해 '제목', '소제목 3개 이상', '500자 이내의 본문' 구조를 명확히 갖추어 출력"이라고 명시되어 있음 (※ 본문 글자수는 요구사항의 "500자 이상"과 반대로 "500자 이내"로 설정되어 있어, 제출 전 한 번 확인 필요)
   - **X(C)**: 280자 이내 요약. 프롬프트가 `주제/타겟/톤/핵심 키워드`를 변수로 받는 템플릿 구조이며, 조건에 "**톤**"을 입력값으로 직접 조정 가능하도록 설계, "280자 이내", "첫 문장은 관심을 끌도록 작성", "핵심 내용을 간결하게 전달", "해시태그 2~3개 포함"이라고 명시되어 있음
4. **PiAPI/NanoBanana (이미지 생성)** — 생성된 텍스트(또는 주제)를 바탕으로 소셜 미디어에 활용 가능한 품질의 대표 이미지를 생성한다.
5. **Notion (저장)** — API 연결을 통해 생성된 텍스트와 이미지 URL을 플랫폼별로 구분된 데이터베이스 항목에 자동 저장한다.
   - `A/B/C_notion_Result.png`는 Make 시나리오의 Notion 모듈(Create a Data Source Item)이 **Google Gemini AI(텍스트)와 PiAPI/NanoBanana(이미지)의 실제 output 값을 그대로 받아 노션 데이터베이스 필드에 입력한 결과 화면**이다. 즉 모듈 설정 캡처가 아니라 **실제 생성된 최종 콘텐츠와 생성 이미지가 담긴 산출물 캡처**다.
     - **A (인스타그램)**: "텍스트내용" 컬럼에 완성된 캡션 본문 + 해시태그가 저장되어 있고, "Files & media" 컬럼에 PiAPI/NanoBanana가 생성한 이미지 썸네일이 첨부되어 있음
     - **B (블로그)**: "프롬포트" 컬럼에 블로그 제목/본문 결과가 저장되어 있고, "파일과 미디어" 컬럼에 생성 이미지 썸네일이 첨부되어 있음 (화면 너비상 본문 일부가 잘려 보일 수 있음)
     - **C (X)**: "Content" 컬럼에 280자 이내 요약 결과가, "Image" 컬럼에 생성 이미지 썸네일이 첨부되어 있음
     - 각 행의 "URL"/"여기로" 컬럼에 보이는 `img.theapi.app/...` 링크는 PiAPI/NanoBanana가 반환한 **실제 생성 이미지의 원본 URL**이다.

## 5. 프롬프트 수정 과정 기록 (초안 → 수정 → 최종)

| 단계 | 내용 |
|---|---|
| 초안 | 플랫폼별 텍스트 생성 프롬프트에 글자 수 제한 없음 |
| 수정 | 글자 수 제한을 500자 이내로 적용 |
| 최종 | 플랫폼별 특성을 반영하여 세분화 — 인스타그램: 짧은 캡션 + 해시태그 10개 내외 / 블로그: 500자 이상 본문 + 소제목 구조 / X: 280자 이내 요약 |

> ※ 위 표는 A/B/[C_ai_prompt.png](https://github.com/Xn0w/ia-codyssey/blob/main/B2/3/images/C_ai_prompt.png) 캡처와 함께, 초안 → 수정 → 최종 단계별 프롬프트 원문을 캡처 또는 텍스트로 첨부하면 더 완성도가 높아진다.
