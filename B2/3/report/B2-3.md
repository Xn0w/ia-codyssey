# AI 기반 소셜 미디어 콘텐츠 자동 생성 시스템 — 워크플로우 설명 문서

## 1. 프로젝트 개요

하나의 주제(키워드)를 입력하면 Make 자동화 워크플로우를 통해 **인스타그램 / 블로그 / X(구 트위터)** 3개 플랫폼에 맞는 텍스트와 대표 이미지를 동시에 생성하고, 결과물을 노션 데이터베이스에 플랫폼별로 자동 저장하는 시스템이다. 생성형 AI(Google Gemini)로 텍스트를, 이미지 생성 AI(PiAPI/NanoBanana)로 대표 이미지를 만들며, 각 플랫폼의 특성(글자 수, 해시태그, 톤앤매너)을 프롬프트 설계에 반영했다.

## 3. 워크플로우 단계별 역할 및 연결 구조

전체 구조: `Google Forms(트리거) → Router(3분기) → [Google Gemini AI → PiAPI/NanoBanana → Notion] ×3`

| 단계 | 모듈 | 역할 | 관련 캡처 |
|---|---|---|---|
| 0 | 설계 초안~최종 | 워크플로우 전체 구조의 설계 변경 과정 | design01.png ~ design05.png |
| 1 | Google Forms | 주제 입력 시 자동화 워크플로우를 트리거 | (Term Test1 폼 캡처) |
| 2 | Router | 입력값을 인스타그램(A) / 블로그(B) / X(C) 3개 분기로 분리 | Router_Filter_A.png, Router_Filter_B.png, Router_Filter_C.png |
| 3-A/B/C | Google Gemini AI | 분기별 플랫폼 특성(글자 수, 해시태그, 본문 구조)에 맞는 텍스트 생성 | A_ai_prompt.png, B_ai_prompt.png, C_ai_prompt.png |
| 4-A/B/C | PiAPI/NanoBanana | 콘텐츠 주제에 맞는 대표 이미지 생성 | A_piapi.png, B_piapi.png, C_piapi.png |
| 5-A/B/C | Notion 연동 | 생성된 텍스트·이미지를 플랫폼별로 구분하여 저장 | A/B/C_notion_connection.png (API 연결), A/B/C_notion_Fields.png (필드 매핑), A/B/C_notion_Result.png (저장 결과) |

### 단계별 상세 설명

1. **Google Forms (트리거)** — 사용자가 주제를 입력하면 워크플로우가 즉시 실행된다.
2. **Router (분기)** — 하나의 입력을 3개 경로로 동시에 분기하여 플랫폼별 처리를 병렬로 수행한다.
3. **Google Gemini AI (텍스트 생성)** — 분기마다 별도 프롬프트를 사용해 플랫폼 특성에 맞는 톤앤매너와 글자 수로 텍스트를 생성한다.
   - 인스타그램(A): 짧은 캡션 + 해시태그 10개 내외
   - 블로그(B): 500자 이상 본문 + 소제목 구조
   - X(C): 280자 이내 요약
4. **PiAPI/NanoBanana (이미지 생성)** — 생성된 텍스트(또는 주제)를 바탕으로 소셜 미디어에 활용 가능한 품질의 대표 이미지를 생성한다.
5. **Notion (저장)** — API 연결을 통해 생성된 텍스트와 이미지 URL을 플랫폼별로 구분된 데이터베이스 항목에 자동 저장한다.

## 5. 프롬프트 수정 과정 기록 (초안 → 수정 → 최종)

| 단계 | 내용 |
|---|---|
| 초안 | 플랫폼별 텍스트 생성 프롬프트에 글자 수 제한 없음 |
| 수정 | 글자 수 제한을 500자 이내로 적용 |
| 최종 | 플랫폼별 특성을 반영하여 세분화 — 인스타그램: 짧은 캡션 + 해시태그 10개 내외 / 블로그: 500자 이상 본문 + 소제목 구조 / X: 280자 이내 요약 |

> ※ 위 표는 A/B/C_ai_prompt.png 캡처와 함께, 초안 → 수정 → 최종 단계별 프롬프트 원문을 캡처 또는 텍스트로 첨부하면 더 완성도가 높아진다.
